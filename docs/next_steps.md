# 后续优化方向（模型细节阶段完成后）

> 目标：在不继续扩充微观模型细节的前提下，提升系统级能力、可用性与可验证性。

## 已完成 ✓
- ~~桌面与部署~~：Tauri 桌面应用打包、PyInstaller sidecar、Docker 部署已实现
- ~~基础偏振模型~~：PolarizationRotator、PolarizationPDL、PolarizationWaveplate、PolarizationController
- ~~光学滤波器~~：OpticalFilter 支持多种响应形状与相位模式
- ~~观测仪器完善~~：OSAProbe、ESAProbe、ScopeProbe（时域）

## P0（优先）
- 多信道/WDM 支持：多光载波源、波长栅格、XPM/FWM 简化模型、通道间相互作用评估。
- 放大器与噪声体系：EDFA/ASE、OSNR、光电混合噪声链路一致性。
- 仿真引擎稳态与性能：chunk/stream 处理长波形、GPU/CPU 内存路径优化、自动采样率/时长推导。
- 结果稳定性：统一 dB/线性功率标度、输出归一化策略、数值稳定保护与警告。

## P1（中期）
- 模型校准与验证：标准案例对照、解析解回归、实验数据对比入口。
- 输出分析工具：星座图、EVM/BER 估计、RBW/VBW 控制、统计窗口与平均。
- 模板与批量：链路模板库、参数扫描/批处理、自动报告导出。
- UI/UX 增强：中英文国际化完善、拖拽优化、快捷键、撤销/重做、图导出为 PNG/SVG。

## P2（长期）
- 混合信号与硬件链路：DAC/ADC、驱动器非线性、时钟抖动、定时恢复。
- 更复杂网络：多段光链路与分支、拓扑级优化与容差分析。
- 云端计算：远程仿真任务队列、大规模参数扫描、结果云存储。
- 插件系统：用户自定义 Block、第三方模型集成、Python/JS 插件 API。

## 备注
- 以上方向保持模块化：新增器件与链路能力优先用可组合的小模块实现。
- 优先保持参数默认可运行，且输出可解释、可复现。
